# Сценарии Hanru

Короткие рецепты «у меня есть X — хочу Y». Везде `<книга>` — папка книги (создаётся командой `hanru new`).

## 0. Первый запуск (один раз)

```
install.cmd            # окружение + команда hanru
hanru setup            # провайдер → ключ → модели → профиль (мастер с подсказками)
hanru doctor           # проверка: ключи, связь, ответ каждой модели
```
Без вопросов (для скриптов): `hanru setup --provider openrouter --key sk-... --strong <модель> --fast <модель> --profile economy`.

## 1. Купил книгу, есть EPUB → хочу русский EPUB

```
hanru new "D:\Загрузки\книга.epub" --to "D:\Книги"
hanru run "D:\Книги\книга" --export epub
```
`new` режет книгу по оглавлению, достаёт обложку и автора, определяет язык и показывает оценку токенов.
`run` сам готовит глоссарий и библию, переводит, проверяет и собирает книгу.

## 2. Сначала попробовать на нескольких главах

```
hanru run "<книга>" -c 1-5
hanru export "<книга>" --format epub -c 1-5      # прочитать пробу
hanru run "<книга>"                              # остальное (готовое заново не переводится)
```

## 3. Длинный роман (сотни глав) — в фоне

```
hanru estimate "<книга>"                         # токены и время по профилям
hanru run "<книга>" --background --export all    # сразу возвращает управление
hanru status "<книга>"                           # готово / осталось / ETA / токены
hanru status "<книга>" --watch                   # следить до конца
hanru stop "<книга>"                             # мягко остановить
hanru continue "<книга>" --background            # продолжить
```
Перевод идёт волнами по 25 глав: перед каждой волной находятся новые имена, сверяется пол, в библию
дописываются новые персонажи. Если провайдер «лёг», задача сама останавливается после нескольких
ошибок подряд, а не сжигает всю книгу.

## 4. Компьютер выключился / процесс убит / нажал Ctrl+C

```
hanru continue "<книга>"
```
Прогресс сохраняется после каждого батча (несколько абзацев), запись атомарная. Готовые главы не
переводятся заново, начатые продолжаются со своей стадии (черновик → починка → рецензент).

## 5. Меньше токенов (готов ждать дольше)

```
hanru run "<книга>" --profile economy
hanru profiles --set economy --book "<книга>"    # закрепить для книги
```
| профиль | что делает | токены* |
|---|---|---|
| quality | переводчик с полным рассуждением + рецензент на всю главу | ~×4 от balanced |
| balanced | сильный переводчик + рецензент на всю главу (по умолчанию) | 1 |
| economy | быстрая модель, крупные батчи, рецензент только по местам с замечаниями | ~0.4–0.5 |
| local | всё на вашем ПК (Ollama/LM Studio), бесплатно и приватно, медленно | 0 ₽ |

\* по замерам в JOURNAL.md; точная оценка для вашей книги — `hanru estimate`.

## 6. Бесплатно, на своём компьютере

```
ollama pull qwen3:14b                            # или любая модель от ~14B
hanru setup --provider ollama --local qwen3:14b --profile local
hanru run "<книга>"
```

## 7. Другой провайдер / другая модель

```
hanru models                                      # модели всех настроенных провайдеров
hanru models openrouter
hanru setup --provider openrouter --key ... --strong <модель> --reviewer <модель>
```
В REPL: `/model strong openrouter:<модель>`, `/profile economy`. Любой OpenAI-совместимый сервер — в
`hanru.json` → `"providers": {"мой": {"base_url": "http://.../v1"}}`, ключ — `hanru setup --provider мой --key ...`.

## 8. Уже есть перевод (Hermes, человек, сайт) — проверить и починить

Положите `Оригинал/` и `Перевод/` в одну папку (имена файлов «Глава N.txt»):
```
hanru audit "<книга>"            # без LLM: чужие/искажённые имена, пол, числа, иероглифы, обрезанные абзацы
hanru audit "<книга>" --fix      # починить только найденное (корректные абзацы не трогаются)
```
Абзацы выравниваются автоматически, даже если переводчик их делил или склеивал.

## 8а. Нашёл в интернете машинный перевод: путает пол, полно мусора — довести до ума

Оригинал не нужен. Положите главы перевода в `Перевод/` (и копию в `Оригинал/`, если оригинала нет).
```
hanru clean "<книга>"                       # предпросмотр: реклама сайта, заметки и благодарности автора
hanru clean "<книга>" --apply               # убрать (с резервной копией)
hanru cast "<книга>" --suggest              # персонажи и статистика рода по тексту
hanru cast "<книга>" --set "Линь Яо=f:младшая сестра героя" --set "Ся Фань=m"
hanru edit "<книга>" --genders --background # исправить род во всей книге (status / stop / continue)
hanru export "<книга>" --format epub
```
Машинный перевод с китайского ставит мужской род по умолчанию, поэтому «большинство» по тексту врёт
(сестра героя 50 раз «сказал» и 35 раз «сказала»). Пол персонажей задаёте вы (или энциклопедия/вики
романа); статистика `--suggest` подсказывает, кого проверить. Редактор правит только род: правка, которая
меняет больше (похожесть < 85%), отклоняется.

## 9. Один большой TXT или папка глав

```
hanru new "D:\novel.txt"         # режет по заголовкам 第N章 / Глава N / Chapter N
hanru new "D:\Книги\Моя книга"   # папка с Оригинал/Глава N.txt — просто подключить
hanru new "D:\Книги\Моя книга" --fix-breaks   # если предупредит о разорванных абзацах
```
Скачанные с сайтов тексты часто разорваны посреди фраз (жёсткие переносы строк). На таком тексте
переводчик путает абзацы. Из EPUB/TXT Hanru склеивает разрывы сам; для готовой папки — `--fix-breaks`
(с резервной копией оригинала).

## 10. Аудиокнига

Правила в `STYLE.md` (числа цифрами, фразы для восприятия на слух) обязательны для всех книг. Сборка:
`hanru export "<книга>" --format fb2` (FB2 любят читалки с озвучкой) или `--format epub`.

## 11. Тонкая работа с агентом (как Claude Code)

```
hanru "<книга>"                                   # диалог
hanru ask "<книга>" "в главе 7 героиня говорит о себе в мужском роде — найди и исправь"
hanru ask "<книга>" "переименуй Толстяка в Пухляша во всех главах"
```

## 12. Из Hermes / Claude Code / другого агента

- Hermes: `hanru integrate hermes` устанавливает готовый скил `hanru-translator`; дальше просто
  «переведи книгу D:\книга.epub» — Hermes сам запустит перевод в фоне и будет следить за статусом.
- MCP (любой клиент): `hanru mcp "<книга>"` — 30+ инструментов, для долгих задач `job_start` /
  `job_status` / `job_stop` (вызов MCP ограничен ~120 с, поэтому перевод — в фоне).
