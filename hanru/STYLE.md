# Профиль переводчика (глобальный, для всех книг)

Этот файл подмешивается в промт переводчика каждой книги. Книжная «библия» (.hanru/bible.md)
может уточнять и переопределять эти правила.

- Текст готовится для чтения и для аудиокниги: благозвучно, простыми для слуха фразами.
- Числа — цифрами, как в оригинале (включая номер главы); китайские числительные тоже цифрами
  (一千 → 1000, 五百万 → 5000000). Не превращай цифры в слова.
- Деньги: 元/块 → «юаней».
- Названия брендов и машин (Porsche, iPhone) — латиницей, как принято в русском тексте.
- Мат и грубость — передавай эмоцию, но смягчай до уровня, допустимого в аудиокниге.
- Пол персонажа — по местоимениям и прямым указаниям оригинала, не по поведению или роли.
