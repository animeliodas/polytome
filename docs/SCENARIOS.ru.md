# Сценарии Polytome

[English](SCENARIOS.md) · **Русский**

Короткие рецепты «у меня есть X — хочу Y». Везде `<книга>` — папка книги (создаётся командой `polytome new`).

## 0. Первый запуск (один раз)

```
install.cmd               # окружение + команда polytome
polytome setup            # провайдер → ключ → модели → профиль (мастер с подсказками)
polytome doctor           # проверка: ключи, связь, ответ каждой модели
```
Без вопросов (для скриптов): `polytome setup --provider openrouter --key sk-... --strong <модель> --fast <модель> --profile economy --to ru`.

## 1. Купил книгу, есть EPUB → хочу EPUB на своём языке

```
polytome new "D:\Загрузки\книга.epub" --to ru -L "D:\Книги"
polytome run "D:\Книги\книга" --export epub
```
`--to` — язык, на котором читать (по умолчанию — из настроек или язык системы), `-L` — папка-библиотека.
`new` режет книгу по оглавлению, достаёт обложку и автора, определяет язык оригинала и показывает оценку токенов.
`run` сам готовит глоссарий и библию, переводит, проверяет и собирает книгу.

## 1а. Любой язык → любой язык

```
polytome languages                               # языки и какие проверки есть для пары
polytome new "D:\novel.epub" --to en             # китайский → английский (имена — пиньинь: Li Xiaobai)
polytome new "D:\light-novel.epub" --to es       # японский → испанский
polytome new "D:\book.epub" --from en --to ru    # язык оригинала можно указать явно
polytome setup --to en                           # язык перевода по умолчанию для новых книг
```
Перевод работает для любой пары. Детерминированные проверки включаются там, где применимы: имена китайских
персонажей — по Палладию (русский) или пиньиню (языки на латинице); род персонажей и «числа цифрами» —
морфологией русского; остатки письма оригинала — когда письменности разные; пропуски, числа, дубли, глоссарий —
для всех пар. Язык уже созданной книги меняется так же: `polytome new "<папка книги>" --to <код>` (пока в ней
нет перевода).

## 2. Сначала попробовать на нескольких главах

```
polytome run "<книга>" -c 1-5
polytome export "<книга>" --format epub -c 1-5      # прочитать пробу
polytome run "<книга>"                              # остальное (готовое заново не переводится)
```

## 3. Длинный роман (сотни глав) — в фоне

```
polytome estimate "<книга>"                         # токены и время по профилям
polytome run "<книга>" --background --export all    # сразу возвращает управление
polytome status "<книга>"                           # готово / осталось / ETA / токены
polytome status "<книга>" --watch                   # следить до конца
polytome stop "<книга>"                             # мягко остановить
polytome continue "<книга>" --background            # продолжить
```
Перевод идёт волнами по 25 глав: перед каждой волной находятся новые имена, сверяется пол, в библию
дописываются новые персонажи. Если провайдер «лёг», задача сама останавливается после нескольких
ошибок подряд, а не сжигает всю книгу.

## 4. Компьютер выключился / процесс убит / нажал Ctrl+C

```
polytome continue "<книга>"
```
Прогресс сохраняется после каждого батча (несколько абзацев), запись атомарная. Готовые главы не
переводятся заново, начатые продолжаются со своей стадии (черновик → починка → рецензент).

## 5. Меньше токенов (готов ждать дольше)

```
polytome run "<книга>" --profile economy
polytome profiles --set economy --book "<книга>"    # закрепить для книги
```
| профиль | что делает | токены* |
|---|---|---|
| quality | переводчик с полным рассуждением + рецензент на всю главу | ~×4 от balanced |
| balanced | сильный переводчик + рецензент на всю главу (по умолчанию) | 1 |
| economy | быстрая модель, крупные батчи, рецензент только по местам с замечаниями | ~0.4–0.5 |
| local | всё на вашем ПК (Ollama/LM Studio), бесплатно и приватно, медленно | 0 ₽ |

\* по замерам в JOURNAL.md (китайский → русский); точная оценка для вашей книги — `polytome estimate`.

## 6. Бесплатно, на своём компьютере

```
ollama pull qwen3:14b                            # или любая модель от ~14B
polytome setup --provider ollama --local qwen3:14b --profile local
polytome run "<книга>"
```

## 7. Другой провайдер / другая модель

```
polytome models                                      # модели всех настроенных провайдеров
polytome models openrouter
polytome setup --provider openrouter --key ... --strong <модель> --reviewer <модель>
```
В REPL: `/model strong openrouter:<модель>`, `/profile economy`. Любой OpenAI-совместимый сервер — в
`polytome.json` → `"providers": {"мой": {"base_url": "http://.../v1"}}`, ключ — `polytome setup --provider мой --key ...`.

## 8. Уже есть перевод (Hermes, человек, сайт) — проверить и починить

Положите `Оригинал/` и `Перевод/` в одну папку (имена файлов «Глава N.txt» или «Chapter N.txt»):
```
polytome audit "<книга>"            # без LLM: чужие/искажённые имена, пол, числа, остатки оригинала, обрезанные абзацы
polytome audit "<книга>" --fix      # починить только найденное (корректные абзацы не трогаются)
```
Абзацы выравниваются автоматически, даже если переводчик их делил или склеивал; правка сохраняет файл абзац
в абзац.

## 8а. Нашёл в интернете машинный перевод: путает пол, полно мусора — довести до ума

Оригинал не нужен. Положите главы перевода в `Перевод/` (и копию в `Оригинал/`, если оригинала нет).
```
polytome clean "<книга>"                       # предпросмотр: реклама сайта, заметки и благодарности автора
polytome clean "<книга>" --apply               # убрать (с резервной копией)
polytome cast "<книга>" --suggest              # персонажи и статистика рода по тексту
polytome cast "<книга>" --set "Линь Яо=f:младшая сестра героя" --set "Ся Фань=m"
polytome edit "<книга>" --genders --background # исправить род во всей книге (status / stop / continue)
polytome export "<книга>" --format epub
```
Машинный перевод с китайского ставит мужской род по умолчанию, поэтому «большинство» по тексту врёт
(сестра героя 50 раз «сказал» и 35 раз «сказала»). Пол персонажей задаёте вы (или энциклопедия/вики
романа); статистика `--suggest` подсказывает, кого проверить. Редактор правит только род: правка, которая
меняет больше (похожесть < 85%), отклоняется.

## 9. Один большой TXT или папка глав

```
polytome new "D:\novel.txt"          # режет по заголовкам 第N章 / Глава N / Chapter N / Capítulo N …
polytome new "D:\Книги\Моя книга"    # папка с Оригинал/Глава N.txt — просто подключить
polytome new "D:\Книги\Моя книга" --fix-breaks   # если предупредит о разорванных абзацах
```
Скачанные с сайтов тексты часто разорваны посреди фраз (жёсткие переносы строк). На таком тексте
переводчик путает абзацы. Из EPUB/TXT Polytome склеивает разрывы сам; для готовой папки — `--fix-breaks`
(с резервной копией оригинала).

## 10. Аудиокнига

Общие правила — `polytome/styles/<язык>.md` (для русского: числа цифрами, фразы для восприятия на слух; для
остальных языков — `default.md`). Свои правила: `STYLE.md` или `STYLE.<язык>.md` рядом с `polytome.json`.
Сборка: `polytome export "<книга>" --format fb2` (FB2 любят читалки с озвучкой) или `--format epub`.

## 11. Тонкая работа с агентом (как Claude Code)

```
polytome "<книга>"                                   # диалог
polytome ask "<книга>" "в главе 7 героиня говорит о себе в мужском роде — найди и исправь"
polytome ask "<книга>" "переименуй Толстяка в Пухляша во всех главах"
```

## 12. Из Hermes / Claude Code / приложения

- Hermes: `polytome integrate hermes` устанавливает готовый скил `polytome-translator`; дальше просто
  «переведи книгу D:\книга.epub на английский» — Hermes сам запустит перевод в фоне и будет следить за статусом.
- MCP (любой клиент): `polytome mcp "<книга>"` — 30+ инструментов, для долгих задач `job_start` /
  `job_status` / `job_stop` (вызов MCP ограничен ~120 с, поэтому перевод — в фоне).
- Приложения: `from polytome import Polytome` (Python), JSON-RPC `polytome serve`, Android через Chaquopy —
  [INTEGRATION.ru.md](INTEGRATION.ru.md).

## Язык интерфейса

Сообщения CLI — на языке системы (русский или английский). Явно: переменная `POLYTOME_UI_LANG=en` или `ru`.
