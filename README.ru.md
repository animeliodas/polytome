# Polytome — переводчик книг на основе LLM, который сам проверяет свою работу

[English](README.md) · **Русский**

Polytome переводит книги целиком (EPUB, TXT, папки глав) **с любого языка на любой** и сам следит за качеством:
имена, пол персонажей, числа, пропуски и остатки оригинала проверяет **код**, а не модель. Работает с любой
моделью — облачной или на вашем ПК.

Начинался как переводчик китайских веб-новелл, поэтому эта пара отточена лучше всего: китайские имена
транскрибируются детерминированно (Палладий для русского, пиньинь для языков на латинице), а пол персонажей
сверяется с уликами в оригинале.

Три способа работы:
- **Готовые команды** — предсказуемо и экономно: `polytome new` → `polytome run` → `polytome export`.
- **Диалог с агентом** (как Claude Code): «в главе 7 героиня говорит о себе в мужском роде — исправь».
- **Внутри приложения** — API на Python, Android (Chaquopy) или JSON-RPC: [docs/INTEGRATION.ru.md](docs/INTEGRATION.ru.md).

## Быстрый старт

```
install.cmd                                         # один раз (Windows): окружение и команда polytome
polytome setup                                      # провайдер → ключ → модели → профиль
polytome new "D:\Загрузки\книга.epub" --to ru       # создать книгу (главы, обложка, автор, оценка токенов)
polytome run "D:\Загрузки\книга" --export epub      # перевести и собрать EPUB
```
Linux/macOS: `python -m venv .venv && .venv/bin/pip install -e .`, дальше те же команды.
Все сценарии с примерами: **[docs/SCENARIOS.ru.md](docs/SCENARIOS.ru.md)** (длинный роман в фоне, продолжение
после сбоя, экономия токенов, локальные модели, проверка чужого перевода, аудиокнига, Hermes).

## Языки

```
polytome languages                         # языки и какие проверки есть для пары
polytome new книга.epub --to en            # язык чтения; язык оригинала определяется сам
polytome setup --to ru                     # язык чтения по умолчанию для новых книг
```
| проверка | пары |
|---|---|
| пропуски, обрезанные абзацы, числа, дубли/сдвиг абзацев, глоссарий | все |
| остатки письма оригинала (иероглифы, кана, хангыль, кириллица…) | письменности разные |
| китайские имена: детерминированная транскрипция и поиск искажённых вариантов | китайский → русский (Палладий), китайский → языки на латинице (пиньинь) |
| пол персонажей по уликам оригинала (他/她, родство) | китайский → любой |
| грамматический род персонажей, «числа цифрами» | → русский (морфология) |

Любой другой код ISO 639-1 тоже можно указать — модель получит его как название языка. Промты для перевода на
русский настроены и измерены (JOURNAL.md); для остальных языков — английские промты с правилами пары
(пиньинь и термины сянься для китайский → английский, Хепбёрн для японского, оформление диалогов языка перевода…).

## Команды

| команда | что делает |
|---|---|
| `polytome setup` / `polytome doctor` | настроить провайдеров и модели / проверить связь и ключи |
| `polytome new <epub\|txt\|папка> [--to en] [--from zh] [-L библиотека]` | создать книгу |
| `polytome run <книга> [-c 1-50] [--profile economy] [--background] [--export epub]` | перевести |
| `polytome status <книга> [--json\|--watch]` | прогресс, ETA, токены (без LLM) |
| `polytome stop` / `polytome continue <книга>` | мягко остановить / продолжить после сбоя или остановки |
| `polytome estimate <книга>` | токены и время по всем профилям |
| `polytome audit <книга> [--fix]` | проверить перевод (свой или чужой) без LLM; починить найденное |
| `polytome export <книга> --format epub\|fb2\|txt\|all` | собрать книгу |
| `polytome profiles [--set economy [--book <книга>]]` | профили качества/экономии |
| `polytome models [провайдер]` / `polytome languages` | доступные модели / языки |
| `polytome <книга>` / `polytome ask <книга> "задача"` | диалог с агентом / задача одной фразой |
| `polytome integrate hermes` | установить скил для Hermes |
| `polytome mcp <книга>` / `polytome serve` | MCP-сервер для агентов / JSON-RPC API для приложений |

## Профили: качество или экономия

| профиль | переводчик | рецензент | для кого |
|---|---|---|---|
| `quality` | сильная модель с полным рассуждением | вся глава | максимум качества, токены не важны |
| `balanced` | сильная модель без долгих рассуждений | вся глава | по умолчанию |
| `economy` | быстрая модель, крупные батчи | только места с замечаниями | меньше токенов, дольше ждать |
| `local` | модель на вашем ПК | места с замечаниями | бесплатно и приватно |

Профиль задаётся глобально (`polytome profiles --set`), для книги (`--book`) или на один запуск (`--profile`).

## Модели и провайдеры

Провайдеры из коробки: Ollama Cloud, Ollama и LM Studio (локально), llama.cpp, vLLM, OpenRouter, OpenAI,
Anthropic, Google Gemini, DeepSeek, Mistral, Groq, Together, AITunnel. Любой другой OpenAI-совместимый сервер —
одной строкой в `polytome.json`.

Модели раскладываются по **слотам**: `strong` (основной переводчик), `fast` (дешёвая), `agent` (диалог),
`reviewer`, `extractor`, `local`. Мастер `polytome setup` подскажет варианты; без вопросов:
```
polytome setup --provider openrouter --key sk-... --strong <модель> --fast <модель> --profile economy --to ru
```
Ключи хранятся в `secrets.json` (или переменных окружения), не в `polytome.json`. Модель без нативного
tool-calling тоже работает — агент переключается на текстовый протокол сам.

## Надёжность

- Прогресс сохраняется после каждого батча, запись атомарная: выключение ПК не портит файлы, `continue`
  продолжает с места остановки. Проверено жёстким убийством процесса посреди перевода.
- Длинные романы переводятся волнами по 25 глав: глоссарий и библия растут вместе с книгой.
- Если провайдер недоступен, задача останавливается сама, а не сжигает книгу на ошибках.
- Разорванные посреди фразы абзацы (частая беда скачанных текстов) склеиваются при импорте; сдвиг и
  дубли абзацев ловятся проверкой главы. Проверено на романе в 100 глав (JOURNAL.md).

## Качество: что проверяет код (китайский → русский)

- **Имена**: транскрипция по Палладию (pypinyin), имя в переводе сверяется с иероглифами абзаца — «Су Чэнь»
  вместо героя или «Синя» вместо «Синья» ловятся и чинятся.
- **Пол**: улики из оригинала («X，Y的弟弟», 姐姐/哥哥, «名叫X的女子») против глоссария + морфология
  («Шэнь Син улыбнулся» при героине).
- **Числа** цифрами для аудиокниг («500 миллионов» → «500000000»), китайская пунктуация, пропуски,
  обрезанные абзацы, остатки иероглифов.

Общие правила перевода — в `polytome/styles/<язык>.md` (для русского: аудиокнига, числа цифрами); свои —
`STYLE.md` или `STYLE.<язык>.md` рядом с `polytome.json`. Они важнее библии книги.

## Встраивание в приложения

```python
from polytome import Polytome
h = Polytome({"providers": {"openrouter": {"api_key": "sk-..."}}, "slots": {"strong": "openrouter:<модель>"},
              "target_lang": "ru"})
book = h.import_book("книга.epub")["path"]
h.translate(book, chapters="1-5", on_event=print)
h.chapter(book, 1)          # {"source": [...], "translation": [...]} — абзацы 1:1
```
То же для любых языков программирования: `polytome serve` (JSON-RPC по stdin/stdout) или `call(method, json)` из
Kotlin через Chaquopy. Методы, события, пример для Android — [docs/INTEGRATION.ru.md](docs/INTEGRATION.ru.md).

## Hermes

```
polytome integrate hermes
```
Копирует скил `polytome-translator` в Hermes и прописывает путь к Polytome. Дальше в Hermes: «переведи книгу
D:\книга.epub». Hermes запустит перевод в фоне, будет следить за статусом (с учётом лимита ячейки 300 с),
продолжит после сбоя и соберёт EPUB.

## Язык интерфейса

Сообщения CLI и API — на языке системы: русский в русской системе, иначе английский. Явно:
`POLYTOME_UI_LANG=ru` или `en`. Строки — в `polytome/locales/en.json`; `python tools/i18n_wrap.py check`
показывает непереведённые.
